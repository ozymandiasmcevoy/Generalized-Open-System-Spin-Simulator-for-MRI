# Generalized Open-System Spin Simulator for MRI

A tissue-configurable density-matrix framework for simulating proton-spin MRI dynamics using Liouville–von Neumann and Lindblad master equations.

[**Launch Premade Interactive Simulations →**](https://ozymandiasmcevoy.github.io/Generalized-Open-System-Spin-Simulator-for-MRI/)

## Overview

This project models voxel-scale nuclear magnetic resonance dynamics as the evolution of spin-1/2 hydrogen density matrices.

The simulations begin from a thermally populated proton-spin ensemble, apply idealized RF excitation through unitary rotations, and evolve the resulting state under a Zeeman Hamiltonian with optional longitudinal relaxation and transverse dephasing.  The tissue, field strength, repetition time, pulse count, voxel dimensions, flip angle, simulation duration, and plotting resolution can be modified near the beginning of each script.

Unlike a conventional Bloch-equation simulator, the framework directly evolves the density matrix. Bloch-vector coordinates and physical voxel magnetic moments are then recovered from spin expectation values.

The framework supports:

- pure unitary Zeeman evolution;
- mixed thermal-equilibrium states;
- tissue-dependent proton density, T1, and T2;
- configurable static field strengths;
- single-pulse and repeated-pulse experiments;
- longitudinal recovery and transverse dephasing;
- driven steady-state behavior;
- Wigner and Husimi-Q spin phase-space representations;
- interactive Plotly animations exported as standalone HTML files.

## Current Simulations

1. **Hamiltonian Bloch Precession**

   Simulates nonrelaxing laboratory-frame proton-spin precession following a single RF excitation. The accompanying Fourier-transform panel identifies the Larmor-frequency content of the spin expectation values.

2. **Lindbladian T2 Relaxation**

   Simulates a single excitation followed by transverse dephasing and longitudinal relaxation. The animation displays the decaying transverse voxel magnetization over several multiples of the selected tissue's T2.

3. **Repeated-Pulse T1 and Steady-State Dynamics**

   Applies a sequence of fixed-flip-angle RF rotations separated by configurable repetition times. The simulation demonstrates incomplete longitudinal recovery, progressive saturation, and convergence toward a flip-angle-dependent driven steady state.

4. **Wigner and Husimi-Q Phase-Space Dynamics**

   Maps the evolving spin-1/2 density matrix onto spherical Wigner and Husimi-Q representations, providing complementary phase-space views of the same open-system evolution.

## Physical Model

The simulated particles are spin-1/2 hydrogen nuclei with gyromagnetic ratio

```math
\gamma_{\mathrm{H}}
=
2\pi\left(42.577\times10^6\right)
\ \mathrm{rad\,s^{-1}\,T^{-1}}.
```

The spin operators are

```math
S_i
=
\frac{\hbar}{2}\sigma_i,
```

where ```math\sigma_i``` are the Pauli matrices.

Evolution in the static magnetic field is generated by the Zeeman Hamiltonian

```math
H
=
-\gamma_{\mathrm{H}}
\left(
B_xS_x+B_yS_y+B_zS_z
\right).
```

In the absence of relaxation, the density matrix follows the Liouville–von Neumann equation:

```math
\frac{d\rho}{dt}
=
-\frac{i}{\hbar}[H,\rho].
```

The corresponding unitary evolution is

```math
\rho(t)
=
U(t)\rho(0)U^\dagger(t),
\qquad
U(t)
=
\exp\left(-\frac{iHt}{\hbar}\right).
```

## Thermal Equilibrium and RF Excitation

The initial density matrix is constructed from the nuclear Zeeman energy splitting at room temperature:

```math
\Delta E
=
\hbar\gamma_{\mathrm{H}}|\mathbf B_0|.
```

The equilibrium spin-state populations are determined from the Boltzmann ratio

```math
\frac{p_{\mathrm{upper}}}{p_{\mathrm{lower}}}
=
\exp\left(
-\frac{\Delta E}{k_BT}
\right).
```

RF excitation is modeled as an ideal, instantaneous rotation about the \(x\)-axis:

```math
U_x(\alpha)
=
\exp\left(
-\frac{i\alpha S_x}{\hbar}
\right),
```

with

```math
\rho^{+}
=
U_x(\alpha)\rho^{-}U_x^\dagger(\alpha).
```

The default flip angle is the tissue- and repetition-time-dependent Ernst angle:

```math
\alpha_E
=
\cos^{-1}\left(
e^{-TR/T_1}
\right).
```

## Open-System Dynamics

Relaxation and dephasing are introduced through the Lindblad master equation:

```math
\frac{d\rho}{dt}
=
-\frac{i}{\hbar}[H,\rho]
+
\sum_k
\left(
L_k\rho L_k^\dagger
-
\frac{1}{2}
\left\{
L_k^\dagger L_k,\rho
\right\}
\right).
```

The simulator includes:

- a phase-damping channel for transverse dephasing;
- a lowering channel for relaxation toward the lower-energy state;
- a thermally weighted raising channel;
- Zeeman evolution through the Hamiltonian commutator.

The pure-dephasing contribution is chosen so the combined longitudinal and phase-damping channels reproduce the selected tissue's T1 and T2:

```math
\Gamma_{\phi}
=
\frac{1}{2}
\left(
\frac{1}{T_2}
-
\frac{1}{2T_1}
\right).
```

The master equation is vectorized into a Liouville-space superoperator, allowing the density matrix to be propagated through matrix exponentiation.

## Tissue and Field Configuration

The simulations include representative configurations for:

- gray matter;
- white matter;
- arterial blood;
- cerebrospinal fluid.

Each tissue is assigned a relative proton density and field-dependent T1 and T2 values.

Available static-field configurations include:
- 3T;
- 7T;
- 9.4T.

The selected tissue and field determine the relaxation constants, repetition time, equilibrium polarization, proton count, and default Ernst angle.

These values are intended to provide physically reasonable simulation conditions and can be modified to represent a particular experiment.

## From Spin Expectations to Voxel Magnetization

The density-matrix evolution is converted into observable spin expectations through

```math
\langle S_i\rangle_t
=
\mathrm{Tr}\left[
\rho(t)S_i
\right].
```

The normalized Bloch-vector coordinates are

```math
r_i(t)
=
\frac{2}{\hbar}
\langle S_i\rangle_t.
```

The single-proton magnetic moment is calculated from

```math
\mu_i(t)
=
\gamma_{\mathrm{H}}
\langle S_i\rangle_t.
```

For a voxel containing \(N_{\mathrm{voxel}}\) protons, the simulated voxel magnetic moment is

```math
M_i(t)
=
N_{\mathrm{voxel}}\mu_i(t),
```

where

```math
N_{\mathrm{voxel}}
=
n_{\mathrm{H}}V_{\mathrm{voxel}}.
```

This connects the quantum density-matrix description to the voxel-scale magnetization visualized in the interactive Bloch plots.

## Wigner and Husimi-Q Representations

The Wigner and Husimi-Q simulations represent the evolving spin state on the unit sphere.

For a spherical direction

```math
\mathbf n
=
\left(
\sin\theta\cos\phi,
\sin\theta\sin\phi,
\cos\theta
\right),
```

the spin-direction operator is

```math
\boldsymbol{\sigma}\cdot\mathbf n
=
n_x\sigma_x+n_y\sigma_y+n_z\sigma_z.
```

The spin-1/2 Wigner kernel is

```math
\Delta_W(\mathbf n)
=
\frac{
I+\sqrt{3}\,\boldsymbol{\sigma}\cdot\mathbf n
}{
4\pi
},
```

and the Husimi-Q kernel is

```math
\Delta_Q(\mathbf n)
=
\frac{
I+\boldsymbol{\sigma}\cdot\mathbf n
}{
4\pi
}.
```

The time-dependent spherical distributions are evaluated as

```math
W(\mathbf n,t)
=
\mathrm{Tr}
\left[
\rho(t)\Delta_W(\mathbf n)
\right].
```

and

```math
Q(\mathbf n,t)
=
\mathrm{Tr}
\left[
\rho(t)\Delta_Q(\mathbf n)
\right].
```

The Wigner representation is a quasiprobability distribution and may contain negative values. The Husimi-\(Q\) representation is a smoother nonnegative probability distribution.

Both are displayed as animated color densities on spherical phase space.

## Assumptions and Limitations

The current simulations make several simplifying assumptions:

- hydrogen nuclei are represented as noninteracting spin-1/2 systems;
- the static field is spatially uniform;
- RF pulses are ideal and instantaneous;
- tissue properties are spatially homogeneous within each voxel;
- diffusion, chemical shift, tissue-susceptibility, exchange, and spin-spin coupling are not included;
- relaxation is represented through idealized Markovian Lindblad channels;
- tissue parameters are representative values rather than a strong experimental parameters.

The simulations are intended as a transparent computational framework for connecting density-matrix dynamics, open-system quantum mechanics, and conventional MRI magnetization behavior.

## Development Status

The current framework focuses on configurable proton-spin dynamics for voxel-scale MRI simulation.

Planned extensions include:

- validation against established open-system solvers such as QuTiP;
- more sophisticated coupling and interaction models;
- spatially varying tissue and phantom simulations.

A longer-term direction is to generalize the same open-system framework to weakly anharmonic superconducting circuits such as transmon qubits.
